# Alter Ego

🇧🇷 [Ler em português](README.md)

A chat program written in Python with [Eel](https://github.com/python-eel/Eel) that opens a visual-novel-style window where you talk to Alter Ego. She chats through AI (Gemini), has an avatar whose expression changes with the emotion of each reply, a typing effect with sound, SQLite chat history, in-chat commands, plain-language error messages, and two languages (Portuguese and English) switched with the `PT | EN` button.

```
while friend.exists():
    listen()
```

| Info | Details |
|---|---|
| **Interface** | desktop window (Chrome, Edge or the default browser) at `localhost:8765` |
| **AI** | Gemini (`gemini-3.6-flash` by default, via `google-genai`) |
| **Languages** | Portuguese and English, switched with the `PT \| EN` button |
| **Avatar** | 7 expressions that change with the emotion of the reply |
| **History** | SQLite, kept between runs |
| **Highlights** | typing effect with sound, conversation memory, automatic retries, plain-language errors |

## Features

### AI chat (Gemini)
- You type in the input field and Alter Ego answers in the language chosen with the `PT | EN` button
- The conversation has memory: the last 40 saved messages are sent back to the model as context (the value is `MAX_CONTEXT_MESSAGES` in `core/config.py`)
- The context always starts with one of your messages, which is the format Gemini requires
- The personality is a system instruction (editable in `core/personality.py`): kind, helpful, a little shy but brave, loyal and friendly, with a slight tone of a curious computer
- Alter Ego always refers to herself in the feminine and answers in up to three short sentences, unless you ask for more detail
- Replies are always plain running text, with no markdown, lists, emojis or code blocks, because they appear in a visual-novel dialogue box
- She helps with any subject, such as studying and programming, without breaking character
- If Gemini is overloaded (a 5xx error, such as 503), the program retries up to 3 times, waiting 2 s and then 4 s
- If Gemini does not answer within 30 seconds, the program tells you instead of staying on "Thinking..." forever
- Only question/answer pairs that succeeded are saved to the history: failed replies never reach the database

### API key
- On first launch, if there is no key, the program asks you to paste yours (what you type is shown as dots and never reaches the log)
- The key is saved in the `.env` next to the program, on this computer only
- The `/key` command changes the key later, and a hand-edited `.env` still works

### Emotions and avatar
Gemini starts every reply with a tag in square brackets, and the program uses that tag to switch the avatar image. The tag is never shown on screen.

| Emotion | When it appears |
|---|---|
| `[neutro]` | neutral, default tone |
| `[feliz]` | joy, greetings |
| `[timido]` | shyness |
| `[preocupado]` | worry (also used for error messages) |
| `[pensativo]` | reflection |
| `[triste]` | sadness |
| `[surpreso]` | surprise |

- The tag accepts uppercase and accents (`[Tímido]` becomes `timido`)
- An unknown or missing tag falls back to `neutro`, and the text is still shown normally
- Square brackets in the middle of the text (like `[1, 2, 3]`) are not treated as a tag
- Images live in `web/expressoes/<name>` and the program accepts `.jpg`, `.jpeg`, `.png` and `.webp`
- If the image for an expression does not exist, `web/expressoes/fundo.png` (the monitor without the character) is shown instead of breaking the screen. If that is missing too, the monitor stays empty, with only the light border. In both cases, the name of the missing expression is logged in the browser console (`F12`)

### Terminal and effects
- Text appears letter by letter (typing effect), with longer pauses on punctuation
- A short "blip" sound plays every two visible letters (generated by the browser, no audio files)
- Clicking the terminal skips the animation
- The log shows only the latest exchange, like a visual novel; the full history stays saved in the database
- While waiting for the reply, "Thinking..." appears with animated dots
- On startup, the program shows a greeting, or "Good to see you again!" if there was a previous conversation
- `F11` toggles fullscreen

### Chat commands
| Command | Description |
|---|---|
| `/ajuda` / `/help` | shows the list of commands |
| `/som` / `/sound` | turns the typing sound on or off |
| `/idioma pt` / `/lang en` (or `/language`) | switches the language; with no argument, toggles between PT and EN |
| `/limpar` / `/clear` | erases the whole conversation history (asks for confirmation) |
| `/tela` / `/screen` | toggles fullscreen |
| `/chave` / `/key` | asks for the Gemini key and saves it (replaces the current one) |

Command names exist in both languages at the same time, regardless of the chosen language.

### History
- Each message is saved in SQLite (`data/historico.db`) with its role (`user` or `model`), text and date
- The model's reply is stored with the emotion tag, so the model keeps seeing the pattern in later messages
- The database only accepts the roles `user` and `model`
- `/clear` wipes the database and restarts the conversation with Gemini

## Languages (pt/en)
- The `PT | EN` button (top right corner) or the `/lang` command switches the language of both the interface and the AI
- When you switch, the screen is cleared (the saved history stays intact), the AI instruction is rebuilt in the new language, and Alter Ego introduces herself again
- The choice is saved in the browser, per address. That is why the port is fixed (`8765`): if it changed, the chosen language would be forgotten
- On the first run, the language follows the browser language (English if it starts with `en`, otherwise Portuguese)
- Errors are also shown in the chosen language
- Emotion tags stay the same (`feliz`, `timido`...) in both languages, because the program uses those names to pick the image

## When something goes wrong
Errors are shown on screen in plain language, and the technical cause of each one is written to `alter_ego.log`.

| Situation | What the program does |
|---|---|
| No API key | asks for it on startup; if it goes missing later, tells you to use `/key` |
| Invalid key | asks you to use `/key` and enter another one |
| API usage limit | asks you to wait a moment |
| Model not found | shows the model name and asks you to check `GEMINI_MODEL` |
| Takes too long | suggests checking your internet connection |
| No internet | says it could not connect |
| Gemini service unstable | retries 3 times before warning you |
| Empty reply (only the tag) | asks you to rephrase the question |
| Any other error | shows a generic message and writes the details to the log |

If you see "Something went wrong" or "Something unexpected happened", open `alter_ego.log` to find out why.

## Download the ready-made app (Windows)

1. On the repository's [Releases](../../releases) tab, download `AlterEgo-windows.zip` and extract the folder (don't open it from inside the zip)
2. Open `AlterEgo.exe`
3. On first launch, the program asks for your Gemini key: create a free one at [Google AI Studio](https://aistudio.google.com/apikey) and paste it in the input field

Google Chrome or Microsoft Edge must be installed. The app is not digitally signed, so Windows may show "Windows protected your PC": click **More info** and then **Run anyway**.

## How to run from source

1. Install Python 3.10+ and the dependencies:
   ```
   pip install -r requirements.txt
   ```
2. Copy `.env.example` to `.env` and put your [Google AI Studio](https://aistudio.google.com/apikey) key in `GEMINI_API_KEY`. Or skip this step: if you start without a key, the program asks you to paste yours. Never push `.env` to GitHub (it is already in `.gitignore`)
3. Run:
   ```
   python main.py
   ```

The program opens a window in Chrome or Edge. If neither is found, it falls back to the default browser.

### Configuration (`.env`)

| Variable | Purpose | Default |
|---|---|---|
| `GEMINI_API_KEY` | Gemini API key (required; if missing, the program asks for it on startup) | empty |
| `GEMINI_MODEL` | Gemini model | `gemini-3.6-flash` |
| `ALTER_EGO_BROWSER` | browser to use: `chrome`, `edge` or `default` | `chrome` |
| `ALTER_EGO_DB` | path of the history database | `data/historico.db` |

Model names change over time. If you see "The model was not found", check the current name in the Google AI Studio documentation and update `GEMINI_MODEL`.

Other options live in `core/config.py`: API timeout (`TIMEOUT_API_SEGUNDOS`, 30 s), context messages (`MAX_CONTEXT_MESSAGES`, 40) and window size (`WINDOW_SIZE`, 1000 × 580).

## How to add a new emotion
1. Add the name to `EMOCOES` (`core/emocao.py`)
2. Put the image at `web/expressoes/<name>.jpg` (or `.jpeg`, `.png`, `.webp`)
3. Add the name to `NOMES_EXPRESSOES` in `web/script.js` (and in `web/teste_zoom.html`, if you use it)

The AI instruction is built from `EMOCOES`, so the new tag goes into the prompt on its own.

```
├── requirements.txt

│   └── workflows/
│       └── release.yml          # builds the app on GitHub and publishes it to Releases
├── .env                         # your Gemini key (created by you or by the program; not pushed to GitHub)
├── .env.example                 # template for .env
├── alter_ego.log                # generated automatically: unexpected errors
├── core/                        # the program's "brain"
│   ├── config.py                # key, model, timeout, paths for .env, database and log
│   ├── chave.py                 # checks and saves the API key in the .env
│   ├── ai_client.py             # talks to Gemini, with memory and retries
│   ├── history.py               # SQLite history
│   ├── personality.py           # personality and greetings, in Portuguese and English
│   ├── emocao.py                # emotion tags ([feliz], [timido]...)
│   └── erros.py                 # all error messages, in both languages
├── data/
│   └── historico.db             # generated automatically (not pushed to GitHub)
├── web/                         # interface
│   ├── index.html
│   ├── style.css
│   ├── script.js                # terminal, typing, sound, avatar, commands and language
│   ├── teste_zoom.html          # compares web/expressoes with web/expressoes_normalizadas
│   ├── expressoes/              # one image per emotion, plus fundo.png (used when one is missing)
│   └── expressoes_normalizadas/ # version with matched zoom (optional)
└── tests/                       # unit tests
    ├── test_ai_client.py
    ├── test_chave.py
    ├── test_emocao.py
    ├── test_erros.py
    ├── test_history.py
    └── test_personality.py
```

`web/teste_zoom.html` is a helper page to compare `web/expressoes/` with `web/expressoes_normalizadas/` (the version with matched zoom). To make the program use the normalized version, change `PASTA_EXPRESSOES` in `script.js`.

## Tests

```
python -m unittest discover tests
```

Install the dependencies first (`pip install -r requirements.txt`). The tests use neither the internet nor the API key: `ai_client` is tested with a fake Gemini. They cover emotion tags, error classification and messages (in both languages), the history, the personality, the API key and the AI client (retries, errors and session restart).

## Building an executable (.exe)

Inside the app, the `.env`, the `data/` folder (history) and `alter_ego.log` live **next to `AlterEgo.exe`**, and the `web/` folder is bundled with it. There are two ways to build it:

**On GitHub (recommended: it publishes to the Releases tab by itself):**

```
git tag v1.0.0
git push origin v1.0.0
```

The `.github/workflows/release.yml` workflow runs the tests, builds the app and attaches `AlterEgo-windows.zip` to the release. You can also run it by hand from the **Actions** tab.

**On your computer (Windows):** double-click `build.bat`. The app ends up in `dist/AlterEgo/`; zip that folder to send it to someone. The equivalent command, with PyInstaller installed, is `python -m eel main.py web --onedir --noconsole --name AlterEgo`.

Never put your key inside the app: whoever receives the program pastes their own key on first launch.

## Libraries used

- [`eel`](https://pypi.org/project/Eel/): connects Python to the HTML/JS front-end
- [`google-genai`](https://pypi.org/project/google-genai/): Gemini integration
- [`python-dotenv`](https://pypi.org/project/python-dotenv/): reads environment variables
- `sqlite3` (ships with Python): conversation history
